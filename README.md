Green Trails — A Nature & Travel Blog Platform

Green Trails is a Django-powered blogging platform focused on sharing stories about nature, travel, exploration, and sustainable living.

It allows adventurers, explorers, and storytellers to publish their journeys, discover trending travel experiences, and connect through inspiring content.

Features

1)Publish travel experiences

2)Share nature photography stories

3)Trending travel blogs section

4)Search travel destinations

5)Like & engage with posts

6)User authentication system

7)Individual blog detail view

8)lean, calm, nature-themed UI

Tech Stack

Backend: Django (Python)

Frontend: HTML, CSS, JavaScript

Database: MongoDB

Version Control: Git & GitHub
